# agent-ask-orama v0.3.0

**Released 2026-11-16. A minor release.** The agent's licence and open-source preparation, the
image's bases pinned by digest, and the engine-issue link in refusals made a setting, since
[v0.2.1](v0.2.1.md). Refusals no longer link to a tracker unless one is configured, a change a
person can see, which is why this is a minor release and not a patch. Image:
`docker.io/oramasearch/agent-ask-orama:v0.3.0`.

This release is the tree of `dev` after #66 (`50a3a4c`), with these notes, the version and the
README's release line. The prompt is still **v17**.

### The licence — #66

agent-ask-orama is released under the MIT licence, copyright OramaSearch, Inc. (`LICENSE`,
`COPYRIGHT`). Every source file carries `SPDX-License-Identifier: MIT`, added and checked by
`tools/spdx-headers.py`. `THIRD_PARTY_LICENSES` lists the licence of every dependency. Contributions
are made under `CLA.md` (contributors assign copyright to OramaSearch, Inc.), following
`CONTRIBUTING.md` and `CODE_OF_CONDUCT.md`. `tools/sbom.py` writes the software bill of materials in
SPDX 2.3 and CycloneDX, regenerated for this release.

### A security policy — #63

`SECURITY.md` says how to report a vulnerability privately and what we commit to in reply.

### The engine-issue link is a setting — #67

When Ask Orama says a methodology is not supported yet, it names the engine issue that tracks it
(`zetta#N`). The link to that issue now comes from `ZETTA_ISSUE_URL`, a template with `{n}` for the
number (for example `https://github.com/<owner>/zetta/issues/{n}`). Unset, the issue is named
without a link, so an install never points people at a tracker it was not given. Prompt v17's one
line that carried a fixed tracker address reads the same way; v14 to v16 stay as they were, for
trace history.

The eval reports of an earlier live run are removed from `reports/`; its README says how a report is
produced.

### The image's bases are pinned by digest — #64

Each `FROM` and `COPY --from` names the multi-platform index digest its tag pointed to, so a later
build of the same source gets the same base. A new base is a reviewed change of the digest.

## Before it rolls: settings

No setting is required. One optional setting is new: `ZETTA_ISSUE_URL` (above). The settings of
[v0.2.0](v0.2.0.md#before-it-rolls-settings) still apply (`AGENT_SERVICE_TOKEN` and `LAKE_URL`
required, both rendered by the operator). `git diff v0.2.1..v0.3.0 -- src` adds no other environment
read.

## Not included

- **Claiming tasks by reference and naming the task on every call** (#65, for lake#871): deferred
  for review, not in this release.
- No conversation memory across restarts (conversations are in memory, bounded).
- No explicit workspace ids on data-plane calls, and no idle backoff on the bus.
- No live eval results for prompts v12 to v17, and no live `methodology_draft` eval.

## Known issues

Security-relevant first. All open at this tag.

1. **The image bundles GPL and LGPL code** (#68): it is built on `python:3.12-slim` (Debian: glibc,
   bash, coreutils, dpkg, readline), so the image is not published. It moves to `scratch` with
   static binaries before it is.
2. **The eval grader passes a reply that names no issue when `ZETTA_ISSUE_URL` is unset** (#69):
   the grader accepts the issue's name or its link, and with no link configured the empty link
   matches every reply. One test fails on it:
   `tests/test_agent.py::test_evals_are_generated_from_the_index_and_graded_by_rules`.
3. #12: no explicit `workspace_id` on data-plane calls and delegations, and no idle backoff on the
   bus.
4. #27: the draft's lock hashes are read from `pypi.org`, not confirmed reachable from the pod, and
   no live `methodology_draft` eval.
5. #25, #23: the live evals have not run on v12 to v17, nor the count evals.
6. lake#1191: outside the Quickstart, Ask Orama cannot find "the last-uploaded dataset", because
   `list_datasets` has no upload time.
7. #3: models are listed by project id instead of project name.

## Where it has run

operator's default image; moving it to `:v0.3.0` is a separate operator change.
